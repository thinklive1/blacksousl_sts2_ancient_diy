# BS Ancient

《杀戮尖塔 2》先古之民扩展 Mod。当前主要新增 3 位地图先古之民，并将开局涅奥替换为古兰.吉涅尔；另有一个“古兰.吉涅尔?”图鉴分类用于展示开局相关的先古遗物。

## 先古之民出现规则

- 诺登：第 2 层出现。
- 普利凯特：第 3 层出现。
- 梅贝尔：第 2 层或第 3 层出现，一局最多一次。
- 古兰.吉涅尔：替换开局涅奥的外观和文本。
- 古兰.吉涅尔?：只用于图鉴展示，不会在地图中出现。
- 如果开启“只生成 Mod 先古”，第 2 层会在诺登/梅贝尔中随机，第 3 层会在普利凯特/梅贝尔中随机。

## 设置开关

这些设置可以在游戏内的 Mod 图形化设置界面修改，也可以手动编辑 mod 目录下的 `bs_ancient_config.cfg`。图形化设置和配置文件使用同一组开关；更改后按下保存按钮会写入配置文件。

`bs_ancient_config.cfg` 是 JSON 格式配置文件，默认内容如下：

```json
{
  "OnlyUseModAncients": true,
  "DisableModAncients": false,
  "ReplaceNeowAppearance": true,
  "GrandGuignolInitialRelicChance": 30
}
```

- `OnlyUseModAncients`：是否只生成本 Mod 的地图先古之民。设为 `true` 时，第 2 层只会从诺登/梅贝尔中选择，第 3 层只会从普利凯特/梅贝尔中选择；设为 `false` 时，新增先古会进入候选池，但不会屏蔽原版或其他 Mod 的先古。更改后需要重启游戏并新开一局。
- `DisableModAncients`：是否完全禁用本 Mod 的地图先古之民。设为 `true` 时，诺登、普利凯特、梅贝尔不会出现在地图中，并且优先于 `OnlyUseModAncients` 生效。更改后需要重启游戏并新开一局。
- `ReplaceNeowAppearance`：是否将开局涅奥的外观、名称、标题和相关对话替换为古兰.吉涅尔。设为 `false` 时，涅奥相关显示恢复原版。更改后需要重启游戏。
- `GrandGuignolInitialRelicChance`：古兰初始遗物替换开局正面选项的概率，范围 0-100，默认 30。更改后需要重启游戏并新开一局。

## 古兰.吉涅尔?

这个分类展示开局相关的先古遗物；这些遗物不会显示在事件遗物池分类中。

- 再思扑克：可能出现在古兰开局选项。获得上一局剩余金币，并从上一局牌组的最多 3 张可用原版卡中选择 1 张获得。没有有效上局记录、上局不是原版职业、多人环境下不会出现。
- 芋虫之烟：可能出现在古兰开局选项。火堆处可以以最大生命为代价选择并升级 1 张牌，不消耗火堆选项次数，最多 3 次；消耗依次为 3/5/8 点最大生命。
- 公爵夫人的菜单：可能出现在古兰开局选项。获得卡牌奖励时可以选择供应；供应 3 次后，根据供应的整组卡牌品质总分获得奖励。普通卡 1 分，罕见卡 2 分，稀有卡 3 分；12 分及以下获得 200 金币和 1 组罕见卡奖励，13-18 分获得 300 金币和 1 组稀有卡奖励，19 分及以上获得 500 金币和 2 组稀有卡奖励。若获得浮木，该遗物失效。
- 天使的羽毛：可能出现在古兰开局选项。每场战斗第一次受到生命伤害时，获得等量活力；进入第 2 层后变为天使的羽毛?。天使的羽毛?会在每次受到生命伤害时获得等量活力；进入第 3 层后变为暴杀天使的羽毛。暴杀天使的羽毛会在每次受到生命伤害时获得等量活力；每场战斗第一次受伤后，攻击造成生命伤害时恢复生命，恢复总量不超过该次受伤值，状态栏会显示剩余可恢复量。

## 诺登

选项：

- 选项 1：时间女王的祝福 / 冬之钟的盟约 / 白兔的发饰 / 停滞的齿轮
- 选项 2：卡达斯之梦 / 独角兽的皇家纹章 / 狮子的皇家纹章
- 选项 3：白兔的誓约 / 童话作者的羽毛笔 / 宠物猫的项圈。若牌组没有 2 张可变化牌，或已拥有宠物，宠物猫的项圈不会出现。
- 选项 4：白皇后的士兵棋子

遗物：

- 时间女王的祝福：给牌组 1 张牌附加重演。重演牌在消耗堆时会在回合开始自动再次打出，每场战斗最多 3 次。
- 冬之钟的盟约：战斗开始时，将格尔达、弗洛伦斯、幽灵猎人洗入抽牌堆。格尔达抽到时获得 1 层不死并消耗；弗洛伦斯抽到时获得 3 层再生、抽 3 张牌并消耗；幽灵猎人抽到时获得 3 点力量、抽 3 张牌并消耗。
- 停滞的齿轮：拾取时获得 1 张同名牌。停滞的齿轮为 1 费先古技能，消耗，选择手牌 1 张牌添加再演；升级后保留。本回合手动打出再演牌后，下回合开始时会按该牌本场战斗的打出次数自动打出。自动打出计入次数，但不会单独触发下回合再演。
- 宠物猫的项圈：拾取时，选择牌组 2 张牌变化为柴郡猫的微笑与黛娜的撕咬。微笑为 0 费技能，获得 4 格挡，升级后 6 格挡；每触发 2 次获得 1 层无实体。撕咬为 0 费攻击，破除敌人所有格挡并造成 15 伤害，升级后 20 伤害。两张猫牌合计每回合最多触发 1 次效果。
- 卡达斯之梦：休息处只能休息；休息时额外回复 30% 最大生命，并随机升级 3 张牌。
- 童话作者的羽毛笔：获得 1 张改变之权能。改变之权能为 3 费攻击，保留，造成 39 伤害，清除自身所有负面状态，消耗；升级后造成 48 伤害。
- 白兔的发饰：结束回合时，若敌人的攻击总伤害大于等于你的当前生命、格挡、覆甲与奥斯提当前生命之和，立即获得 1 个额外回合。每场战斗限一次。
- 独角兽的皇家纹章：战斗开始时获得 2 敏捷。每当敌人的攻击未对你造成生命伤害时，立即对其造成等额反击伤害。
- 狮子的皇家纹章：敌人无法获得格挡、缓冲、覆甲和无实体。每当敌人获得正面状态时，获得 1 力量。
- 白兔的誓约：回合开始时，若生命低于 50%，获得 1 能量；每场战斗首次触发时获得 3 层再生。
- 白皇后的士兵棋子：将本层地图前 5 排节点改为 4 场普通战斗和 1 场精英战斗，原路线不变。完成全部试炼后升格为白皇后。
- 白皇后：可以随意选择下一层路线，不限次数。

## 普利凯特

选项：

- 选项 1：红女王的签名专辑 / 普利凯特的骰子 / 暴魔的电影胶卷
- 选项 2：爱丽丝的缎带 / 普利凯特的化妆镜 / 杀人鬼的电影胶卷。多人环境下，普利凯特的化妆镜不会出现。
- 选项 3：普利凯特的誓约 / 蟇?ｋ蟆大･ｳ縺溘 / 童话作者的羽毛笔。默认概率为 45% / 10% / 45%；若牌组中诅咒大于等于 3 张，概率变为 10% / 80% / 10%。
- 选项 4：红皇后的士兵棋子

遗物：

- 红女王的签名专辑：每回合开始时，随机将 1 张当前手牌在本场战斗内减少 1 费。
- 普利凯特的骰子：每回合开始时获得 1 能量；战斗中所有牌的攻击和格挡点数随机上下浮动 3 点。
- 暴魔的电影胶卷：战斗开始时获得暴魔。暴魔无法获得格挡；攻击造成生命伤害时回复等量生命；从第二回合开始，每回合开始时失去当前生命的一半，但不会因此死亡。
- 爱丽丝的缎带：一次性遗物。死亡时复活至满血，并获得 10 力量。
- 普利凯特的化妆镜：获得 1 张红女王的化妆镜。红女王的化妆镜为 0 费先古技能，虚无；选择移出弃牌堆并复制抽牌堆到弃牌堆，或移出抽牌堆并复制弃牌堆到抽牌堆。被移出的牌不会进入消耗堆，也不会触发消耗相关效果。升级后移除虚无。
- 蟇?ｋ蟆大･ｳ縺溘：将牌组中的所有诅咒变化为雋ｴ譁ｹ繧呈?縺。雋ｴ譁ｹ繧呈?縺为 0 费先古诅咒，消耗，虚无；被消耗时受到 1 点伤害，抽 1 张牌，在抽牌堆和弃牌堆各加入 1 张复制，并随机获得 1 层无实体、1 层不死、2 点力量、1 点敏捷、5 点覆甲、1 层发狂，或抽 2 张牌。单人游戏中，每次打出雋ｴ譁ｹ繧呈?縺有 5% 概率驨o咇輠??vf墈荖鞷?悢篓。
- 杀人鬼的电影胶卷：战斗中，每个敌人第一次被你用攻击击中时，若该敌人不是攻击意图，则击晕该敌人并给予 3 层易伤。
- 普利凯特的誓约：每 2 场非 Boss 战斗，获得 1 组 3 选 1 稀有卡牌奖励。
- 红皇后的士兵棋子：将本层地图前 5 排节点改为 3 场普通战斗和 2 场精英战斗，原路线不变。完成全部试炼后升格为红皇后。
- 红皇后：非 Boss 战斗开始时，将所有敌人的当前生命降为 1。

## 梅贝尔

选项：

- 选项 1：从 3 个随机宠爱中选择 1 个。候选为长发公主的宠爱 / 人鱼公主的宠爱 / 青蛙公主的宠爱 / 白雪公主的宠爱 / 灰姑娘的宠爱。
- 选项 2：海兰里斯酒 / 舞台落幕。
- 选项 3：永恒之虚无 / 夜空的神秘 / 混沌的赠礼。

遗物：

- 长发公主的宠爱：每回合少抽 1 张牌；每 3 个玩家回合获得 1 个额外回合，计数跨战斗保留。
- 人鱼公主的宠爱：失去 30 最大生命；最大能量 +1。
- 青蛙公主的宠爱：每次给予敌人负面状态时，额外给予 1 次相同负面；然后有 20% 概率给自己 1 层虚弱、易伤或脆弱。
- 白雪公主的宠爱：战斗开始时失去 5 敏捷；受到敌人攻击伤害减半。
- 灰姑娘的宠爱：每回合开始失去 3 力量；每回合结束清除自身所有负面状态。
- 海兰里斯酒：获得 1 张同名牌。海兰里斯酒为 2/1 费先古能力牌，虚无，打出后获得额外回合效果。
- 舞台落幕：获得 1 张同名牌。舞台落幕为 0 费先古技能，补满手牌和能量，获得发狂；之后打出 8 张非舞台落幕牌后强制死亡。升级后移除虚无。
- 永恒之虚无：进入战斗时，为卡组中的所有牌赋予虚无；每回合获得 1 张附带虚无的随机本职业牌。
- 夜空的神秘：每回合有 50% 概率使你打出的第一张牌额外打出 1 次。
- 混沌的赠礼：选择最多 3 张非 X 费攻击或技能牌，融合为 1 张混沌融合。融合牌继承素材费用、词条和标签，类型随机，最多随机保留 1 个附魔；打出时随机顺序、随机目标打出所有素材效果。融合牌无法升级。

## 随机事件

- 蜡人偶：第 1-3 层可能出现。可以选择获得双生的蜡人偶或孤单的蜡人偶；如果牌组里没有至少一对同名牌，双生选项会被禁用。
- 双生的蜡人偶：选择一张拥有同名牌的牌，再从同名牌中选择 2 张附魔双生。打出双生牌时，会打出另一张同名双生牌。
- 孤单的蜡人偶：选择 1 张牌附魔孤单。打出孤单牌时，随机消耗一张同名牌；若成功消耗，该牌获得重放 1。第一次打出时不会立刻重放。
- 鸟类歌唱家：第 2 层前半可能出现。事件会随机影响地图上 7 个后续怪物节点，进入受影响节点时，敌人当前生命值减半。选择静待变化会失去 10 点生命并标记受影响节点；选择转身就跑则不会标记节点。
- 骇人饿兽：第 2 层可能出现。可以选择获得骇人饿兽，或花费 100 金币获得一件普通或罕见遗物。骇人饿兽拾取时选择 1 张攻击牌附魔进食；进食牌造成的伤害初始为 150%，每场战斗后降低 15%，每场战斗结束时，每个成功斩杀提高 50%，最低 50%，最高 150%。如果每个玩家都没有可用选项，该事件不会出现
- 女王的蛋挞：第 1 层可能出现。可以选择吃掉蛋挞获得 8 最大生命，或留下蛋挞获得女王的蛋挞遗物并解锁后续特殊事件。
- 女王的蛋挞遗物：第 2 层的下一个事件会变为红心女王。
- 红心女王：第 2 层特殊事件，需要女王的蛋挞。可以选择获得红心女王的斩首架，或获得 200 金币。
- 红心女王的斩首架：拾取时获得 1 张同名牌。红心女王的斩首架为 0 费攻击，保留，消耗，造成 10 伤害，升级后 15 伤害，并附带处刑。
- 处刑：对爪牙敌人的伤害翻倍。若成功击杀敌人，立即返回手牌；否则被消耗。此牌杀死的敌人禁止复活。复活效果只会在确认击杀后移除。
- 友善的史莱姆：第 1-2 层可能出现。可以选择点头试好、与她握手或与她拥抱，分别获得同名遗物；三个遗物图标相同，但效果不同。
- 友善的史莱姆遗物：点头试好会选择 1 张攻击或技能牌附魔溶解；握手会受到 7 点伤害并选择 2 张；拥抱会受到 15 点伤害并选择 3 张。如果没有足够可附魔牌，或生命不足以支付伤害，对应选项会被禁用。
- 溶解：为这张牌添加消耗。打出后，这张牌的伤害和格挡数值永久减少 1；可减少数值全部降为 0 时，从牌组中移除。
- 温柔的馈赠：第 3 层可能出现，牌组中有附魔卡牌时才会出现。可以选择获得迷你雪人，或拒绝馈赠。
- 迷你雪人：拾取时去除所有卡牌附魔；战斗开始时，以邪气侵蚀所有牌。
- 拒绝馈赠：随机 1 张牌获得邪气附魔；如果该牌已有附魔，会被邪气替换。
- 邪气：打出带有邪气的牌时，获得 1 层邪气。回合结束时结算一次：失去等同邪气层数的生命，并从随机敌人吸取等量力量、覆甲和生命。
- 永无终焉的茶会：第 1-3 层可能出现。回答帽匠的问题后，可以饮下可疑的红茶、购买可疑的帽子，或休息恢复 15 点生命。
- 水银：通过茶会获得。拾取时获得 1 张水银。水银为事件技能牌，保留，消耗；会复制上一张非 X 费牌的费用与效果，卡名和卡面不变。未升级时，回合结束后重置复制效果；升级后不会重置。
- 可疑的帽子：通过茶会花费 106 金币获得；若没有可复制遗物，无法购买。始终复制最右侧的原版非先古遗物效果，并在悬浮标注中显示当前复制目标。不会复制 Mod 遗物、先古遗物或自身。

## 其他新增遗物

- 渡渡快跑：进入非 Boss 战斗时，若生命值低于 20，跳过这场战斗。只能触发一次。

## 多人限制

多人环境不会出现：

- 长发公主的宠爱
- 海兰里斯酒
- 普利凯特的化妆镜
- 渡渡快跑
- 白皇后的士兵棋子 / 白皇后
- 红皇后的士兵棋子 / 红皇后
- 再思扑克
- 芋虫之烟
- 公爵夫人的菜单

部分仍可在多人环境出现的随机类效果仍需要更多测试，尤其是夜空的神秘、混沌的赠礼、普利凯特的骰子、红女王的签名专辑。
