# 亡灵契约师部分重做

一个用于修改《杀戮尖塔 2》原版卡牌、遗物和其他玩法内容的独立模组工程。

当前新增十张卡牌：死生契阔、负能量吸收、共赴黄泉、此恨绵绵、血誓、黑暗仪式、饮鸩、借尸还魂、灵魂虚影、同仇敌忾。灵魂虚影在常规卡池中替代纠缠。

## 目录

- `Scripts/Patches`：使用 Harmony 修改原版内容。
- `Scripts/Cards`：新增卡牌。
- `Scripts/Relics`：新增遗物。
- `sts2diy/localization/zhs` 和 `sts2diy/localization/eng`：本地化文本。
- `sts2diy/assets`：卡图、遗物图及其他 PCK 资源。

## 构建

- `dotnet build`：编译 DLL，并将 DLL、Mod 清单、中英文 README 和已有 PCK 同步到游戏的 `mods/sts2diy` 及项目的 `upload/content`。不会重新导出 PCK。
- `dotnet build -t:ExportPck`：先编译，再使用 Godot headless 重新导出 PCK，并同步到上述两个目录；新增或修改本地化、美术等资源后使用。
- 包含游戏 0.111 / 0.113 的独立实现，根目录加载器按游戏版本自动选择；图片和本地化共用一份 PCK。
- Godot 内部发布与测试构建不会部署中间 DLL。上传区不包含玩家配置、`docs` 或美术审核稿，也不会因编译而自动上传工坊。
- 导出超时限制为60秒，失败时不会继续同步该次 PCK。内部 .NET 发布需要的运行时包须先由 NuGet 正常还原。

工程依赖 `STS2 RitsuLib`。首次构建会由 NuGet 还原依赖。

## 灾厄调整

同时支持游戏 0.111.x、0.113.x，依赖 RitsuLib 0.6.15 或更高版本。0.111 实现针对公开 API 快照编译，仍需匹配版本的游戏实测。

- 原版卡牌直接或通过能力给予的灾厄，改为原始数值的 1.5 倍，向下取整。
- 精神过载、Death、Underworld 及其后续能力完全保留原版灾厄逻辑，不放大，也不额外反噬。
- 每次施加时，施加者额外获得原始数值三分之一的灾厄，向下取整。
- 多目标牌每次打出只结算一次自身反噬，不按敌人数重复结算。
- 原本对自己施加灾厄的效果也会放大并额外反噬；新增反噬本身不会再放大。
- 不修改其他 Mod 的灾厄，也不放大本 Mod 新增的吸收、翻倍和转移机制。
- 单纯检查灾厄斩杀线的效果不额外产生灾厄。

例如原始 13 层，给予目标 19 层，同时自身获得 4 层。

灾厄之衣为1费罕见能力：每给予4次灾厄，获得1点能量；升级后获得2点能量，费用和触发次数不变。重复打出的收益叠加，共用每4次触发的计数。

负能量脉冲获得7（9）点格挡，给予所有敌人16（22）层灾厄，自身获得3（5）层灾厄。不会向队友或奥斯提施加灾厄；自身反噬每次打出只结算一次。

共赴黄泉为0费罕见技能，保留且不消耗：翻倍自身灾厄，下回合开始时转移给所有敌人。升级后额外使你本回合不会因灾厄死亡，但不能阻止普通伤害或其他来源的死亡。

此恨绵绵的增伤生效时，奥斯提的状态栏显示原版愤怒图标及当前增伤百分比；回合结束后移除。该状态仅作提示，不会重复计算增伤。

血誓为1（0）费罕见技能：临时失去等同于自身灾厄层数的生命，获得等量格挡。不会消耗灾厄，也不降低生命上限。多次使用累计实际失去的生命，战斗结束后恢复，最多恢复至生命上限；扣血仍可能致死，不提供复活。状态栏显示待恢复生命，记录支持战斗存档。使用独立卡面和生命回转状态图标。

黑暗仪式为1费罕见能力，虚无：在你的回合开始时，失去1点生命上限，召唤8（10）。从打出后的下一个己方回合开始生效；每次打出的效果独立结算，生命上限损失也随之叠加，且战后不返还。使用独立卡面和禁忌祭印状态图标。

饮鸩为0费普通技能，消耗：自身获得6（3）层灾厄，抽2张牌。新增卡的灾厄不受原版卡牌的1.5倍与反噬规则影响；使用独立卡面。

荒疫打击改为造成9（12）点基础伤害，另加自身当前灾厄层数的一半，向下取整，合并为一次攻击。卡面按实际灾厄动态预览伤害，仍正常受力量、虚弱等影响。不再自带给予灾厄或反噬效果，也不消耗自身灾厄。

借尸还魂为0费罕见技能，消耗，升级后获得保留：仅在自身灾厄层数大于等于当前生命值时可打出，立即将自身所有灾厄转移给所有敌人，并获得1层无实体。每个敌人获得完整层数，不受原版灾厄放大与反噬规则影响；不转移队友或奥斯提的灾厄，自动打出也不能绕过条件。使用独立卡面。

负能量吸收为1费普通技能：选择一名敌人，将其一半层数的灾厄转移给自己，获得等量格挡，向下取整。不会吸收其他敌人的灾厄。基础版消耗，升级后移除消耗。

死神形态继续按修改后的规则给予灾厄和自身反噬，并额外使持有者在该状态存在时不会因灾厄死亡。不移除灾厄、不保护队友，也不阻止普通伤害或其他来源的死亡。

## 测试

同仇敌忾为2费普通攻击：你造成6（8）点伤害，然后奥斯提对同一目标造成9（12）点伤害，两段分别使用各自的增伤。奥斯提不在场时仍结算你的攻击；第一段击杀目标或结束战斗时不再攻击。每当自己的奥斯提真正死亡，战斗牌堆中的这张牌本场战斗耗能降低1，最低为0；队友奥斯提、其他生物以及被阻止的死亡不会触发。使用契约师持镰刀与奥斯提共同攻击的独立卡面。

灵魂虚影替代原版纠缠进入常规卡池，为0费罕见能力：每次打出灵魂并完成抽牌后，可以选择抽牌堆中的一张尚无虚无的牌添加虚无，可跳过。升级版还会升级本场战斗中已有和后续生成的自己的灵魂，但不会自动赋予灵魂虚无。重复打出增加每次可选择的张数，升级效果不会被后打出的基础版覆盖。仅修改战斗中的牌，不改变永久牌组；卡面和状态图标复用原版纠缠。纠缠仍保留模型供旧存档读取，不再进入常规奖励、商店和变化候选池。

`dotnet test tests/sts2diy.Tests/sts2diy.Tests.csproj` 检查数值、原版覆盖范围和补丁签名。
测试不替代游戏内的战斗、联机和保存读档验证。
